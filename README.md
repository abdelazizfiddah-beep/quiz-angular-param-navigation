# Quiz Angular – Navigation avec paramètres

## Prérequis

- Node.js (version LTS).
- Angular CLI installé globalement.

```bash
npm install -g @angular/cli

## Installation

git clone https://github.com/abdelazizfiddah-beep/quiz-angular-param-navigation.git
cd quiz-angular-param-navigation
npm install

## Lancement

ng serve

## Puis ouvrir le navigateur sur :

http://localhost:4200
